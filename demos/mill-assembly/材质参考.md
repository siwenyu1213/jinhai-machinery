# 铣床部件材质参考与本地实现

参考与验收日期：2026-10-23。以 Bridgeport Series I 官方实机照片作为颜色、表面处理和反光参照。模型仍是通用炮塔铣床结构演示；没有该设备的 CAD 或测绘数据，不将它称为品牌或型号的精确复刻。

## 实机照片与判断依据

- [官方产品页与照片组](https://bridgeportmachinetools.com/product/milling/series-1/)：整机配色、铸件与裸露金属的区别。官方特征表明确列出磨削主轴、镀铬磨削套筒和镀铬进给丝杠。
- [铣头近照](https://bridgeportmachinetools.com/wp-content/uploads/Bridgeport_KneeMill-Series1_alt4.jpg)：中性灰带光泽漆面，银色套筒、刻度和手柄杆，黑色握把、轴座与紧固件。
- [工作台、手轮与升降台近照](https://bridgeportmachinetools.com/wp-content/uploads/Bridgeport_KneeMill-Series1_alt5.jpg)：裸露工作台有加工痕，T 槽内、端板及轴座较暗，手轮和摇柄有明显金属反射。
- [上部传动壳近照](https://bridgeportmachinetools.com/wp-content/uploads/Bridgeport_KneeMill-Series1_alt6.jpg)：壳体有明亮的抛光金属反射，与下方的灰色漆面不同。
- [NSK 角接触球轴承资料](https://www.nsk.com/products/ball-bearings/angular-contact-ball-bearings/)及 [Schaeffler 主轴轴承资料](https://www.schaeffler.us/us/products-and-solutions/industrial/product-portfolio/rolling_and_plain_bearings/spindle_bearings/)：参考内外圈与滚珠的可辨识结构。本演示选用银色钢圈和钢球的通用表现，不声明实机采用这一具体轴承型号。

下面色值是渲染材质的 sRGB 输入值，由参考图的视觉关系选取；不等于厂家漆号、金属牌号或照片像素采样。环境、反射和色调映射都会影响屏幕上看到的颜色。

## 34 个装配组件的表面分配

| 组件 ID | 表面处理与配色 |
| --- | --- |
| `base`、`column`、`knee`、`ram` | 中性灰铸件漆 `#565c59`，低金属度介质，细橘皮与半光泽漆层；裸露导轨另用加工钢材质 |
| `saddle`、`turret`、`head-adapter`、`head-shell` | 略浅灰铸件漆 `#626864`，仍保留金属轴座、螺栓、接缝和刻度的材质区别 |
| `lift-screw`、`x-leadscrew`、`y-leadscrew` | 明亮加工钢芯、镀铬螺旋齿与青铜色螺母 `#b48c48`；连续螺纹，不以多个圆环代替 |
| `table` | 银灰裸露金属 `#aeb2b1` 叠加钢面颜色、法线和粗糙度贴图；方向性反光、深色槽与黑色端板 |
| `table-left-bearing`、`table-right-bearing` | 深色氧化钢轴座 `#202321`，润滑嘴及端部金属细节保持银色 |
| `spindle`、`drawbar` | 加工钢与镀铬亮面，区别于机身漆面 |
| `lower-bearing`、`upper-bearing` | 银色钢制内外圈、滚珠，中心保持贯通；不再是黑色实心胶圈外观 |
| `quill` | 镀铬钢 `#e0e2e0`，低粗糙度和明暗相间的环境反射 |
| `belt-housing`、`belt-cover` | 抛光铝色 `#d1d3d1`，叠加微细表面贴图；不沿用灰色机身漆 |
| `driven-pulley`、`drive-pulley` | 铝色轮体和加工钢轮毂，带可辨识的金属光泽 |
| `belt` | 亚光黑橡胶 `#121311`，与较有光泽的握把分开 |
| `motor` | 深灰绿色漆 `#363a36`，壳体、端盖和散热筋同一涂装体系 |
| `left-handwheel`、`right-handwheel`、`cross-handwheel`、`fine-feed-wheel` | 镀铬轮缘、轮辐和轮毂；黑色聚合物握把 |
| `lift-crank`、`quill-lever` | 镀铬杆件、黑色圆润握把；铣头前补充深度止挡杆和独立刻度板 |
| `collet` | 加工钢夹持套，深色分缝 |
| `endmill` | 银灰加工刀柄与未涂层刀具钢的视觉表现 `#929793`；保持原有可见刃部与工作台间隙 |
| `head-locks` | 深色氧化钢锁紧杆与锁紧件 |

所有组件的 ID、安装位置、装配阶段和动画路径保留。新增刻度、止挡和轴承内部细节随原组件一起运动，不增加独立装配步骤。

## 贴图、反射与资源来源

- [ambientCG Metal012](https://ambientcg.com/view?id=Metal012)：本地保存 1K JPG 颜色、OpenGL 法线和粗糙度贴图，用于加工钢、工作台、导轨及铝壳微纹。法线、粗糙度以线性数据读取，颜色以 sRGB 读取。法线强度受限，避免把细纹放大为坑洞。依据 [ambientCG 许可](https://docs.ambientcg.com/license/)，资产为 CC0 1.0。
- [Poly Haven Studio Small 09](https://polyhaven.com/a/studio_small_09)，作者 Sergej Majboroda：本地保存 1K HDR，在初始化时预过滤，提供实际光源亮区及暗区的环境反射。依据 [Poly Haven 许可](https://polyhaven.com/license)，资产为 CC0。
- `assets/sources.json` 保存上述 4 个外部文件的来源、作者、字节数与 SHA-256。总计约 3.06 MB。未将参考机床照片当作机身贴图，也未下载品牌标志。
- `assets/quill-scale.svg` 是本地绘制的刻度示意，不含品牌或精度承诺。
- 漆面细纹及 6 片小油膜仍由本地确定性 DataTexture 生成。漆层金属度为 0；镀铬、加工钢、铝和青铜金属度为 1。油膜使用低不透明度与较光滑表层，只留轻微琥珀色渗痕，不模拟流体。
- 全部贴图打包在独立演示内，运行时只访问本地同源文件。图片或 HDR 失败时保留程序材质和本地生成环境，仍可完成滚动装配。退出时释放图片、程序纹理、材质及预过滤环境。

## 验收边界

重点检查整机配色、铣头／工作台近景、旋转中的反光变化，以及桌面和 375px 手机视口的连续装配。精确铸件轮廓、真实刮研花纹、铭牌和每个机械细节仍需 CAD、更多专门建模或实物资料；本次没有将程序模型包装成实拍或精确工业数字孪生。
