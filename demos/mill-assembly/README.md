# 铣床飞入装配独立演示

本目录是独立的 HTML / JavaScript 三维交互预览，不接入网站的 `site/` 页面。使用仓库已安装的 Three.js 与 Vite，不加载外部模型、纹理、字体或 CDN。首版使用代码生成的通用炮塔铣床结构与简单颜色，重点验证外形、透视飞入、旋转和装配节奏。

在仓库根目录执行：

```powershell
npm run demo:build
npm run demo:preview
```

然后在浏览器打开命令输出的本地地址（默认 `http://127.0.0.1:4175/`）。源入口是本目录的 `index.html`；构建输出位置由独立 Vite 配置决定。通过本地 HTTP 服务预览，避免直接双击 HTML 带来的模块加载限制。

- 向下滚动或在触摸屏向上滑动，让零件从镜头左右两侧飞入中央。
- 向上滚动可沿相同路径逆向回放；停止滚动时画面停在当前进度。
- 底部进度条支持拖动与键盘，重播回到开场，查看完成直接显示整机。
- 开启系统“减少动态效果”时，只显示已经完成的组件，跳过近景旋转飞入。
- WebGL 不可用时显示明确说明和六组结构清单。

验证与截图也在仓库根目录执行：

```powershell
npm run test:demo
npm run capture:mill
```

浏览器测试覆盖桌面与 375px 手机尺寸的滚动、反向回放、滑块、键盘、归位、减少动效、同源资源与 WebGL 回退。截图命令用于记录不同装配阶段的画面。

模型与装配顺序用于视觉演示，不对应本厂实物、指定品牌型号或客户案例，不作为制造、维修或实际吊装指导。网页不采集或上传信息。
