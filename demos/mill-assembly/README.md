# 铣床飞入装配独立演示

本目录是独立的 HTML / JavaScript 三维交互预览，不接入网站的 `site/` 页面。使用仓库已安装的 Three.js 与 Vite，不加载外部模型、纹理、字体或 CDN。首版使用代码生成的通用炮塔铣床结构与简单颜色，重点验证外形、透视飞入、旋转和装配节奏。

在仓库根目录执行：

```powershell
npm run demo:build
npm run demo:preview
```

然后在浏览器打开命令输出的本地地址（默认 `http://127.0.0.1:4175/`）。源入口是本目录的 `index.html`；构建输出位置由独立 Vite 配置决定。通过本地 HTTP 服务预览，避免直接双击 HTML 带来的模块加载限制。

- 向下滚动或在触摸屏向上滑动，让所有零件同时从镜头左右两侧飞入，途中已经绕中心旋转并形成上宽下窄的大旋涡，连续收缩至正常旋涡后，在旋绕过程中一起收拢并完成装配。各组件带有独立的多频起伏、倾斜、翻滚和角度偏移，表现被阵风卷起的凌乱运动；进入组装时平滑收稳。
- 飞入保持两侧起点与轻微进度差，前后错开以减少视线重叠；飞入曲线逐渐融入同一个旋转坐标系，不在中央停住后重新起转。
- 整段约 2.23 屏滚动距离；同样的滚轮速度下，飞入过程比上一版延长 40%，中间旋涡阶段的滚动距离缩短 30%；组装仍保留较慢的收拢节奏。
- 从飞入开始到装配完成共旋转一整圈，采用连续的慢起、加速、再减速曲线，中段峰值角速度提高约三分之一。较大的旋涡半径约为正常值的两倍，持续旋转并逐渐收小；大约转过半圈时开始组装，剩余转动与收拢同步完成。
- 全程采用更强的阻尼跟随，衰减时间常数由 0.24 秒调至 0.45 秒，停止滚动后零件继续平滑追赶目标，逐渐减速停稳；向上滚动从当前位置接续逆向回放，不额外增加旋绕圈数。
- 动态阴影采用 1024px 阴影图，桌面像素比上限 1.5、手机上限 1.35，减轻每帧渲染负担。
- 手机旋涡阶段镜头平滑后退，为较宽的上层零件留出空间；装配时逐渐回到整机展示距离。
- 底部进度条支持拖动与键盘，重播回到开场，查看完成直接显示整机。
- 查看内部可将选定外壳变为半透明，观察主轴、轴承与传动件；恢复外壳回到正常显示，不改变装配进度或组件位置。
- 开启系统“减少动态效果”时，跳过飞入和旋绕，在装配完成阶段即时显示整机。
- WebGL 不可用时显示明确说明和六组结构清单。

验证与截图也在仓库根目录执行：

```powershell
npm run test:demo
npm run capture:mill
```

浏览器测试覆盖桌面与 375px 手机尺寸的滚动、反向回放、滑块、键盘、归位、旋涡各高度的左右分布与屏幕容纳、减少动效、同源资源与 WebGL 回退。截图命令用于记录不同装配阶段的画面。

模型与装配顺序用于视觉演示，不对应本厂实物、指定品牌型号或客户案例，不作为制造、维修或实际吊装指导。网页不采集或上传信息。
