# 铣床飞入装配独立演示

最新三机联合预览入口为 `/workshop.html`：铣床、车床与激光切割机共 91 件，完成后按三角队形轮换，可独立拖动查看并分别复原。用户已取消此前的三个图片背景，保留机台名称与轮换联动，见 [联合动效.md](联合动效.md) 与 [背景与机台文字.md](背景与机台文字.md)。三个模型同时用于官网的三维首屏和完整装配页；原铣床预览 `/index.html` 和静态模型初审 `/model-review.html` 仍保留。

本目录保留独立的 HTML / JavaScript 三维交互预览；官网复用同一套模型与材质模块，并提供 `site/machines.html` 完整装配入口。使用仓库已安装的 Three.js 与 Vite，纹理和 HDR 随本地构建一起打包，运行时不依赖外网、模型服务、字体或 CDN。单铣床页保留 34 个独立装配组件，使用程序生成的通用炮塔铣床几何，参照实机照片设置工业漆面、加工金属与少量渗油细节。

在仓库根目录执行：

```powershell
npm run demo:build
npm run demo:preview
```

然后在浏览器打开命令输出的本地地址（默认 `http://127.0.0.1:4175/`）。源入口是本目录的 `index.html`；构建输出位置由独立 Vite 配置决定。通过本地 HTTP 服务预览，避免直接双击 HTML 带来的模块加载限制。

- 向下滚动或在触摸屏向上滑动，让所有零件同时从镜头左右两侧飞入，途中已经绕中心旋转并形成上宽下窄的大旋涡，连续收缩至正常旋涡后，在旋绕过程中一起收拢并完成装配。各组件带有独立的多频起伏、倾斜、翻滚和角度偏移，表现被阵风卷起的凌乱运动；进入组装时平滑收稳。
- 飞入保持两侧起点与轻微进度差，前后错开以减少视线重叠；飞入曲线逐渐融入同一个旋转坐标系，不在中央停住后重新起转。
- 整段约 2.15 屏滚动距离；同样的滚轮速度下，飞入过程比上一版延长 40%，中间旋涡阶段的滚动距离缩短 30%；组装仍保留较慢的收拢节奏。
- 从飞入开始到装配完成共旋转一整圈，采用连续的慢起、加速、再减速曲线，中段峰值角速度提高约三分之一。较大的旋涡半径约为正常值的两倍，持续旋转并逐渐收小；大约转过半圈时开始组装，剩余转动与收拢同步完成。
- 全程采用更强的阻尼跟随，衰减时间常数由 0.24 秒调至 0.45 秒，停止滚动后零件继续平滑追赶目标，逐渐减速停稳；向上滚动从当前位置接续逆向回放，不额外增加旋绕圈数。
- 动态阴影采用 1024px 阴影图，桌面像素比上限 1.5、手机上限 1.35，减轻每帧渲染负担。
- 手机旋涡阶段镜头平滑后退，为较宽的上层零件留出空间；装配时逐渐回到整机展示距离。
- 进度条按有效动画重新映射为 0–100%，完整装配即为滚动终点，去掉旧版 94% 之后的静止尾段。底部进度条支持拖动与键盘，重播回到开场，查看完成直接显示整机。
- 查看内部可将选定外壳变为半透明，观察主轴、轴承与传动件；恢复外壳回到正常显示，不改变装配进度或组件位置。
- 开启系统“减少动态效果”时，跳过飞入和旋绕，在装配完成阶段即时显示整机。
- WebGL 不可用时显示明确说明和六组结构清单。

材质与细节：

- 逐项对照 Bridgeport Series I 官方实机近照重新分配灰色半光漆、裸露钢面、镀铬手轮／套筒、抛光铝罩、深色轴座和橡胶皮带。完整组件、颜色和实拍依据见 [材质参考.md](材质参考.md)。色值是渲染输入，不冒充厂家漆号。
- `materials.js` 保留 7 张 128×128 的确定性 DataTexture。`surface-assets.js` 另从构建包读取 ambientCG Metal012 的 1K 颜色、法线、粗糙度贴图及本地刻度 SVG，区分 sRGB 颜色与线性表面数据。纹理使用 mipmap、线性过滤和最多 4 倍各向异性过滤，降低运动闪烁。
- 漆层是金属度为 0 的细纹半光介质，避免大颗粒水泥感；加工钢和铝加入方向性反光，镀铬控制件更光滑，握把与皮带使用不同粗糙度。油膜更轻、更薄，保留少量琥珀色痕迹和湿润高光。
- 使用本地打包的 Poly Haven Studio Small 09 HDR，初始化时生成预过滤环境反射并释放原始 HDR，保持页面背景。外部资产为 CC0，来源和哈希见 `assets/sources.json`。图片或 HDR 读取失败时回退到程序纹理和本地生成环境，不阻止装配。
- 油膜位于升降台摇柄轴座下方、右进给轴承座端面、套筒露出的下端及铣头进给轴孔附近，共 6 小片；接近实体表面，边缘透明、有短小向下流痕，不投射矩形阴影，也不关闭深度测试。
- 补充螺栓垫圈、六角凹槽、盖板接缝、润滑嘴、铣头深度刻度和止挡杆。轴承具有银色内外圈、滚珠和贯通中心；滚珠合并绘制。三个进给丝杠使用连续梯形螺旋齿形。整机网格仍少于最初的 269 个，控制旋转阶段的绘制负担。
- 油膜是静态表面细节，跟随所属组件运动，不是流体模拟。机器仍是程序生成的结构示意，并非依据 CAD 或实物测绘重建。
