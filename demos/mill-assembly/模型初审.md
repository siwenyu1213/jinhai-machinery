# 模型初审（初稿）

状态：**初稿，待用户审核形体**。本轮只交付静态初审页，供用户先审车床与激光切割机的形体；未做联合龙卷风、未接网站，也未继续三设备联合动画。

## 查看方式

- 本地开发：`npm run demo:dev` 后打开 `/model-review.html`。
- 独立生产构建：`npm run demo:build` 后 `npm run demo:preview`，访问 `/model-review.html`（原有 `/` 铣床预览保持不变）。
- 另一端口预览可用 `npm run demo:preview -- --port 4176`。

## 页面内容

- 一个主视窗，默认显示车床；“车床 / 激光切割机”按钮切换，同一视窗放大查看。
- “正面 / 俯视 / 复位视角”切换视角；可手动拖动旋转、滚轮缩放，无自动旋转、无装配动画。
- 角落显示当前设备名称与实际组件数；底部说明“通用结构示意”。

## 结构部件（通用示意）

- 车床：床脚、床身、主轴箱、卡盘与卡爪、刀架与溜板、尾座、手轮、丝杠、卡盘防护等。
- 激光切割机：机架、地脚、工作台床、导轨、横梁与滑块、激光头与喷嘴、拖链、控制箱、抽风管等。

部件名称以模型实际定义为准，页面右上角显示实际数量。
