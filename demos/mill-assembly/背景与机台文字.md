# 三种背景与轮换机台名称

2026-10-25。本轮在已有三机联合旋涡、三角轮换与独立拖动复原上增加展示层，不修改 91 个组件的装配路径、机台涂装或轮换控制器。按用户反馈，背景采用先生成完整场景图、再接入页面的方式。仅用于独立本地预览，不接入 `site/`，未上传或发布。

## 查看方式

项目根目录执行 `npm run demo:build`，再执行 `npm run demo:preview`，打开 `http://127.0.0.1:4175/workshop.html`。页头三个按钮可以随时切换背景，按钮支持键盘与触摸。也可直接打开：

- [工业摄影棚](http://127.0.0.1:4175/workshop.html?background=studio)
- [旋转气流](http://127.0.0.1:4175/workshop.html?background=airflow)
- [工程图纸](http://127.0.0.1:4175/workshop.html?background=blueprint)

滚动完成装配，或点击“查看完成”，进入三机轮换。点击机台下方名称可把它移到前方；“暂停轮换”同时暂停背景的自主运动。背景切换保留已有进度、所选机台与查看角度。

## 背景

| 版本 | 画面 | 动效 |
| --- | --- | --- |
| 工业摄影棚 | 生成的钢构摄影空间、天窗、真实感窗影与混凝土地面 | 图像缓慢推移与轻微缩放，叠加机台本身的三维接触阴影 |
| 旋转气流 | 生成的环绕烟尘、银灰空气层次、少量暖色微粒与暗色场地 | 图像缓慢呼吸缩放，滚动进度带动轻微视差 |
| 工程图纸 | 生成的实体蓝图、半透明描图纸、纸卷、量具与金属台面 | 图像缓慢推移，保留纸张纹理与层叠阴影 |

三张图片使用内置 `image_gen` 生成，原始尺寸均为 1672×941，转换为同尺寸 WebP 后合计约 691 KB。项目资产位于 [assets/backgrounds](assets/backgrounds/sources.json)，生成来源、尺寸和 SHA-256 见 [sources.json](assets/backgrounds/sources.json)，完整三组提示词见 [prompts.json](assets/backgrounds/prompts.json)。这些是 AI 生成的场景示意，不是本厂实拍；图纸图案也不是实际制造图纸。

页面将图片作为背景主体，不再自行绘制网格、弧线或微粒代替场景素材。CSS 仅提供轻微推移、缩放和视差，烟尘是图像中的内容，不是实时流体模拟。图片随本地构建打包，无第三方运行时请求或字体。背景位于透明 WebGL 画布后，地面使用真实模型灯光的透明阴影承接面，保留接触阴影；没有新增镜面反射渲染通道。图片加载失败会保留简单底色和全部机台操作。

## 机台文字

| 机台 | 文字色 | 对应原涂装 |
| --- | --- | --- |
| 铣床 | `#d6d2bd` 米白 | `WORKSHOP_PALETTES.mill.body` |
| 车床 | `#285f55` 青绿 | `WORKSHOP_PALETTES.lathe.body` |
| 激光切割机 | `#cf6b2e` 橙色 | `WORKSHOP_PALETTES.laser.bodyLight`，该机的橙色涂装 |

色值直接读取 [workshop-palette.js](workshop-palette.js)，不通过独立计时器猜测当前机台。名称跟随 `showcase.state().frontId`，轮换途中旧名称淡出，前方机台到位后新名称显现；手动选择、暂停和自动轮换使用同一状态。米白与橙色文字使用该机的深色涂装作衬底，以保证可读性。常驻的小机台标签继续提供选择功能。

## 性能与降级

背景自主动画只改变 CSS transform，不为 91 个三维组件新建常驻 RAF。原有按需三维渲染、5 秒轮换唤醒、滚动惯性、独立查看与复原保持。暂停轮换、隐藏标签页时暂停背景自主动画；减少动效时背景静止，机台名称即时更新。WebGL 失败时仍可切换三个背景并阅读三机结构，名称不会冒充已显示的设备。

## 验证与截图

运行项目规定的 `npm run build`、`npm test`、`python -X utf8 -m unittest discover -s tests -v`。新增检查位于 [workshop-backdrop.spec.js](../../tests/demo-browser/workshop-backdrop.spec.js) 与 [workshop-backdrop.test.mjs](../../tests/model/workshop-backdrop.test.mjs)，覆盖三背景切换、真实机台涂装色、自动/手动轮换同步、姿态保留、GPU 资源稳定、减少动效与 WebGL 失败回退。

预览服务启动后执行 `npm run capture:workshop`，将桌面 1280×900 与模拟手机 375×812 的三种背景、旋涡和三个完成态记录到本地忽略目录 `artifacts/tmp/workshop-backgrounds/`；报告同时记录实际机台、背景与渲染状态。这些模拟检查不代表真实手机或微信浏览器实测。
